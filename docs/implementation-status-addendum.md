# Implementation status addendum

The historical audit snapshot in `implementation-status.md` predates the current interoperability work. The following capabilities are now implemented beyond that snapshot:

- PPTX import is available from the desktop open dialog, OS open events, and drag-and-drop. Text, common native shape presets (rectangle, rounded rectangle, ellipse, triangle, diamond, and five-point star), connectors, embedded media, notes, canvas size, theme colors/fonts, slide-specific solid backgrounds, presentation-declared slide order, supported title/content/section/two-column/picture/blank layouts with native bounded placeholder geometry, and empty native title/body placeholders converted to editable “Click to add…” text are preserved. Empty or unreadable native picture placeholders remain visible as editable “Click to add Picture” shapes instead of being dropped; valid picture media is still imported as an image. Basic transitions, native table parts, and supported bar/line/pie chart parts are also preserved. Unsupported shape presets and graphic frames remain visible as editable placeholders or bounded rectangle fallbacks with explicit warnings. Other chart types and advanced graphic-frame features remain partial.
- XLSX chart parts are mapped through worksheet and drawing relationships into `ChartModel` entries with chart type, title, and placement anchors. Unsupported or malformed chart mappings remain non-fatal warnings.
- Exported bytes use an atomic write path with fsync, temporary-file cleanup, and backup/restore replacement fallback.
- Core logging now uses a non-blocking size-rolling writer with a 5 MiB active-file bound and four bounded rotated backups; oversized individual records remain intact and rotation failures reopen the current file without crashing the shell.
- DOCX package imports enforce file, archive-entry, XML-part, per-media, and total-media bounds; oversized media is skipped with an explicit compatibility warning.
- The desktop shell now keeps multiple independent document sessions in tabbed views. Each session retains its editor mode, content, path, backend id, and dirty/error state; closing a dirty tab requires confirmation and editor panes remount per session to prevent state leakage.
- All shell open entry points now share one case-insensitive Office/Redoc extension router, so native dialogs, OS open events, and both drag-and-drop paths select the same adapter and reject unsupported types consistently.
- Writer now supports persistent selection-anchored comments with a review sidebar, resolve/reopen/delete actions, and anchor mapping across edits. Review users can mark selected text as insertion/deletion and accept or reject individual tracked changes or all tracked marks; native DOCX w:ins/w:del imports map to those marks, tracked changes export as native revision elements with author/date metadata, supported review comments round-trip through native DOCX comment ranges, hyperlinks round-trip as editable link marks, and a bounded word-level compare summary with a capped before/after review panel can compare either changes since opening or another open Writer session. Advanced revision metadata remains partial.
- Writer page setup now round-trips through DOCX section properties for supported paper sizes, portrait/landscape orientation, margins, 1–4 text columns, headers, footers, and PAGE/NUMPAGES fields; the editor can insert section-break nodes carrying per-section setup, and DOCX import/export preserves those bounded properties. Heading levels H1–H6 and native page-break runs also round-trip. Imported and externally supplied setup metadata is normalized to bounded, renderer-safe values before it reaches the editor or export path. Continuous-section live rendering and advanced field codes remain partial.
- Writer print preview now inherits the active page setup, including A4/Letter/Legal/Executive paper size, portrait/landscape orientation, custom per-edge margins, headers/footers, bounded `{page}`/`{pages}`/`{total}` substitutions, and matching browser `@page` print CSS; preview controls retain a custom-margin state instead of silently reverting to hard-coded defaults.
- Writer exposes bounded PAGE and NUMPAGES fields from the toolbar and Insert → Field menu. Fields render as visible, non-editable nodes in the editor, refresh bounded cached results after layout/status updates, export as native Word field codes with cached results, import both complex and simple Word field forms, and render cached values/placeholders in PDF; unsupported field codes are called out by the compatibility warning path and are not emitted as native fields.
- Writer paragraph alignment, indentation, line height, and bounded spacing-before/after values now emit and re-import as native DOCX paragraph properties with finite-value and range guards.
- Writer bookmarks and internal hyperlinks now use a bounded `bookmark` mark and `internal:<name>` link convention, preserving named anchors and same-document navigation through native DOCX `w:bookmarkStart`/`w:bookmarkEnd` and `w:hyperlink w:anchor` elements; malformed or missing bookmark names are sanitized or omitted safely.
- Writer bookmark authoring is available from the Insert menu, toolbar, context menu, and command palette. It requires a non-empty text selection, normalizes names to Word-compatible identifiers, rejects duplicates, and provides an inline hint for the `internal:`/`#` hyperlink convention.
- Writer hyperlink authoring now normalizes same-document targets and rejects control characters plus unsafe schemes before creating editable link marks; supported external targets are HTTPS/HTTP, mailto, and tel.
- Same-document hyperlink clicks now resolve the named bookmark inside the active Writer session and scroll the editor selection to the target; missing anchors fall back to normal link handling.
- Calc conditional-formatting rules now survive workbook command round-trips and render on visible and merged cells for numeric/text predicates; the sidebar also authors data-bar and three-color-scale rules with bounded, configurable value buckets, and data bars render behind cell content. Native pivot parts remain partial.
- Calc's formula engine now evaluates fixed-rate financial functions `PMT`, `PV`, and `FV`, plus `NPV` and a safeguarded `IRR` solver, with finite-input validation and explicit formula errors for invalid cash flows.
- Calc's formula engine now also evaluates `SUMPRODUCT`, `MAXIFS`, and `MINIFS` with array-shape validation, scalar broadcasting, criteria matching, finite-number guards, and explicit error propagation; date/time coverage now includes `TIME`, `HOUR`, `MINUTE`, `SECOND`, `WEEKDAY`, bounded `NETWORKDAYS`, `DAYS`, `EDATE`, and `WORKDAY`. Statistical compatibility now includes bounded `RANK`/`RANK.EQ`, `QUARTILE`/`QUARTILE.INC`, `CORREL`/`PEARSON`, and `SUMSQ` with tie-aware ranking, shape validation, finite guards, and explicit formula errors. The parser accepts dotted statistical aliases such as `STDEV.P`, `VAR.S`, and `PERCENTILE.INC`, `LET` now evaluates bounded sequential name/value bindings with lexical scope, and bounded array functions `ROWS`, `COLUMNS`, `TRANSPOSE`, `SEQUENCE`, `RANDARRAY`, `HSTACK`, `VSTACK`, `TAKE`, `DROP`, `CHOOSECOLS`, `CHOOSEROWS`, `FILTER`, `UNIQUE`, `SORT`, `SORTBY`, `TOCOL`, `TOROW`, `WRAPROWS`, and `WRAPCOLS` preserve validated dimensions with a hard output-cell cap. Everyday compatibility helpers now include legacy `CONCATENATE`, `COUNTBLANK`, and parity-safe `XOR`. Dynamic-array results now materialize as capped, read-only spill ranges in the workbook model and sheet renderer, with bounded collision detection that reports `#SPILL!`, rechecks blockers, and resolves scalar spill-neighbor references in local and cross-sheet formulas; broader dependency-graph introspection remains partial. Unsupported `LAMBDA` is no longer advertised as working, bringing the generated formula catalog to 137 supported names.
- Calc arithmetic and core numeric functions now reject non-finite intermediate and aggregate results as bounded formula errors, preventing overflow or NaN values from entering cell caches or exported workbooks.
- XLSX export/import now preserves the supported conditional-formatting predicates (numeric comparisons, text contains, data bars, and color scales) and their supported differential styles through native worksheet conditional-format parts; advanced formula rules and theme-based colors remain partial.
- Calc auto-filter ranges and selected list values now round-trip through native XLSX `autoFilter`/`filterColumn` parts, so filtering state remains available when a workbook is reopened; custom filter operators and table/slicer metadata remain partial.
- Calc named ranges now round-trip through native XLSX workbook `definedName` parts, including local worksheet scope; built-in print-area names and formula-only names are intentionally excluded from the editable range list.
- Calc merged cell ranges now round-trip through native worksheet `mergeCells` parts, keeping merged layout intact when an XLSX is reopened.
- Calc list data validation now persists per-cell through the canonical workbook model and native XLSX `dataValidation` parts, including bounded formula-backed source ranges; same-sheet, cross-sheet, and named-range sources resolve into the formula-bar dropdown when the source sheet is cached, while dynamic formulas remain partial.
- Calc cell hyperlinks now round-trip through native XLSX hyperlink and relationship parts, including internal `internal:` anchors; unsupported or malformed hyperlink targets fail safely with an export error rather than producing a broken package.
- Calc now authors cell hyperlinks from the Properties sidebar, normalizes external/internal targets, opens safe external links on Ctrl/Cmd-click, and navigates bounded `internal:Sheet!A1` links across workbook tabs without treating malformed targets as external URLs.
- Calc can insert a bounded inline PNG/JPEG/GIF/WebP image into the active cell, render it in the virtualized grid, preserve it through `.redoc` history/reload, and emit valid PNG/JPEG sources as native XLSX drawings; GIF/WebP or malformed sources remain Redoc-only with an explicit compatibility warning. XLSX import enforces per-image and aggregate media budgets.
- XLSX export validates hyperlink length, control characters, supported external protocols, and internal cell/name targets before writing package XML; invalid links return a typed export error.
- Calc structured table metadata now round-trips through native XLSX table parts, including table name, range, headers, style, and header/totals-row flags; advanced calculated columns and slicer connections remain partial.
- Calc can now create and persist a deterministic one-row-field pivot summary (sum, count, or average) below a selected source range, with refresh-on-workbook-build, active slicer filtering, and removal controls; multi-field pivots and native XLSX pivot parts remain partial.
- Calc now supports named what-if scenarios in `.redoc` workbooks and native SpreadsheetML worksheets: capture the selected cells, apply overrides with recalculation, undo the apply, delete saved scenarios, and round-trip bounded scenario/input-cell metadata through XLSX. Native pivot parts and slicers remain partial.
- Calc now supports bounded slicers in the canonical workbook model and editor: create a slicer from a selected header/data range, toggle or clear value selections, apply the selections while rendering filtered rows, preserve them through `.redoc` history/reload, and emit an explicit native-XLSX fallback warning. Native XLSX slicer parts remain partial.
- Presentation transitions now support bounded fade, slide-left/right, wipe-left/right, zoom, and dissolve effects in editor playback, presenter view, and native PPTX export/import. Entrance fades and zooms persist per-element delay, duration, and reveal order through `.redoc` deck normalization and Presenter playback; PPTX export/import round-trips the supported native fade and zoom effects and their shape targets using PresentationML timing, including bounded authored delay/duration values and deterministic reveal ordering. A full Office-compatible animation timeline and trigger model remain partial.
- Presenter playback now has bounded navigation helpers and controls for pause/resume timer, restart, reveal-all, Home/End, PageUp/PageDown, and R keyboard navigation; boundary behavior is covered by pure tests while advanced triggered timelines remain partial.
- Slides now support bounded element hyperlinks from the Properties panel. Safe HTTP(S), mailto, and tel targets open on Ctrl/Cmd-click, persist through `.redoc`, and round-trip through PPTX external hyperlink relationships; malformed or unsafe targets are rejected and reported by the compatibility inspector.
- Office export now has a preflight compatibility inspector. DOCX, XLSX, and PPTX exports surface deterministic warnings for known fallback paths (unsupported nodes, native pivot parts, unsupported chart types/animations/shapes, and non-inline media) after the file is written; the inspector is intentionally advisory and does not block a user export.
- The large-sheet incremental recalculation budget is repeatably below the 16 ms target (the 10,000-formula benchmark measured 0.58 ms after a single source-cell edit after preserving hot dependency plans and updating only the edited provider cache entry); startup, canvas, package, and export profiling remain part of release certification.

These features remain intentionally partial where Office fidelity requires advanced masters, placeholders, pivot charts, or animation timelines.
