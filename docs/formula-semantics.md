# Formula semantics

Formulas are stored with their leading `=` and evaluated by `crates/formula`. Cell references are 1-based (`A1` is row 1, column 1). Empty cells evaluate as empty values. Division by zero returns `#DIV/0!`; malformed names and unsupported operations return typed formula errors rather than panicking.

Supported function behavior is defined by the registry in `crates/formula/src/functions.rs`. Range arguments are flattened in row-major order. Formula evaluation is deterministic and must remain independent of the frontend.

Date serials use the Excel 1900 date system. `DAYS` compares whole-day serials, `EDATE` clips the source day to the target month when needed, and `WORKDAY` skips Saturday/Sunday plus optional holiday serials. Date conversion is bounded so malformed or extreme inputs return `#VALUE!` instead of overflowing.

`LET` evaluates name/value pairs from left to right and resolves names only within the result expression and later bindings. Name bindings are bounded to prevent pathological formulas; unsupported higher-order functions return a typed formula error rather than silently producing a value.

Array helpers (`ROWS`, `COLUMNS`, `TRANSPOSE`, `SEQUENCE`, `RANDARRAY`, `HSTACK`, `VSTACK`, `TAKE`, `DROP`, `CHOOSECOLS`, `CHOOSEROWS`, `FILTER`, `UNIQUE`, `SORT`, `SORTBY`, `TOCOL`, `TOROW`, `WRAPROWS`, and `WRAPCOLS`) preserve row/column dimensions for composition with reference and aggregate functions. Dynamic results are capped at 100,000 cells and malformed shapes, incompatible include masks, invalid sequence dimensions, invalid random-array bounds, invalid stack or selection shapes, invalid sort arguments, incompatible `SORTBY` keys, invalid flatten options, invalid wrap counts, or empty unique results return `#VALUE!`/`#N/A` rather than allocating without a bound. `SEQUENCE(rows, [columns], [start], [step])` generates a bounded row-major numeric array with defaults of one column, start one, and step one; `RANDARRAY([rows], [columns], [min], [max], [whole_number])` generates bounded volatile values with safe numeric bounds and optional integer mode. `HSTACK` and `VSTACK` concatenate scalar or rectangular arrays, padding shorter inputs with empty cells. `TAKE`/`DROP` select or remove bounded rows and columns, while `CHOOSECOLS`/`CHOOSEROWS` select one or more (including negative-from-end) axes with duplicate selectors preserved. `SORTBY` stably sorts rows or columns by one or more aligned one-dimensional key arrays with per-key ascending/descending order. `TOCOL` and `TOROW` flatten bounded arrays with optional blank/error filtering (including empty text) and row- or column-major scanning. `WRAPROWS` and `WRAPCOLS` reshape bounded vectors into rectangular rows or columns with explicit or `#N/A` padding. Non-finite or non-integral dimensions are rejected. The workbook model materializes bounded spill ranges for rendering, reports `#SPILL!` when a destination is occupied, keeps spill neighbors read-only, and resolves their scalar values in local and cross-sheet formulas; broader dependency-graph introspection for arbitrary spill references remains a follow-up.

Statistical helpers include tie-aware `RANK`/`RANK.EQ`, inclusive `QUARTILE`/`QUARTILE.INC`, and pairwise `CORREL`/`PEARSON`; `SUMSQ` squares finite numeric values across scalar or rectangular arguments. These functions reject malformed arity, incompatible array shapes, non-finite inputs, and zero-variance correlation with bounded formula errors.
